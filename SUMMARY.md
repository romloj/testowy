## 🚀 Jak Uruchomić Animację

### Metoda 1: Najprostsza (1 kliknięcie)
```
1. Pobierz plik: animacja_medsystem.html
2. Kliknij dwukrotnie na plik
3. Otwiera się w przeglądarce
4. Gotowe! ✅
```

### Metoda 2: Przez serwer lokalny (rekomendowana)
```bash
# Terminal (Python)
python -m http.server 8000

# Następnie otwórz:
# http://localhost:8000/animacja_medsystem.html
```

### Metoda 3: W Blenderze (dla profesjonalistów)
```
1. Otwórz Blender 3.6+
2. Przejdź do "Scripting"
3. Otwórz: blender_script.py
4. Kliknij "Run Script"
5. Animacja gotowa w Blenderze!
```

## 🛠️ Dostosowanie i Rozszerzenia

### 1. Zmiana Kolorów
```javascript
// W pliku animacja_medsystem.html
const CONFIG = {
    colors: {
        primary: 0x2E86AB,    // Zmień na swój kolor
        secondary: 0xA23B72,
        accent: 0xFFFFFF,
        background: 0x0f2027
    }
};
```

### 2. Dodawanie Modeli 3D
```javascript
// Import modeli z Blendera
const loader = new THREE.GLTFLoader();
loader.load('prezenter.glb', (gltf) => {
    scene.add(gltf.scene);
});
```

### 3. Nowe Sceny
```javascript
// Dodaj nową scenę do obiektu scenes
scenes.mojaScena = {
    name: "Moja Scena",
    duration: 5,
    animations: [animations.presenterWave],
    onStart: () => {
        // Akcje
    }
};
```

### 4. Dźwięk i Muzyka
```javascript
const audio = new Audio('muzyka.mp3');
audio.loop = true;
audio.play();
```

### 5. Wersja VR (WebXR)
```javascript
import { VRButton } from 'three/examples/jsm/webxr/VRButton.js';
renderer.xr.enabled = true;
document.body.appendChild(VRButton.createButton(renderer));
```
